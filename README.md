# realmonsef.xyz

Personal website for Mohamed Monsef.

## Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- React Router
- Lucide React
- Simple Icons

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Design

The interface uses a restrained neutral palette with a single burnt-orange accent, 8px radius, border-based separation, responsive layouts, and short opacity/transform transitions.

Add the licensed Epic Pro font to `public/fonts/EpicPro.woff2`.
